Agent StarCraft plays original StarCraft voice lines when Claude Code, Codex, or Gemini CLI does something you should hear about. You get "SCV good to go, sir.""My life for Aiur!" at the start, "Job's finished.""Research complete." when a turn ends, and "Nuclear launch detected." when an approval is for git push --force. When your usage runs out, the advisor says what every RTS player already knows: not enough minerals.

Destructive-command alarm

Nuclear launch detected.

When an approval is for something you cannot take back, the cue changes. Recursive force deletes, force pushes, hard resets, dropped tables, mkfs, dd, and their PowerShell cousins all sound the alarm instead of the ordinary prompt.

It is a louder cue, not a safety check. The hook never blocks, approves, logs, or stores the command; only a yes/no flag leaves it.

agent wants to run:
$ git push --force origin main
allow? [y/n]

Usage and context alarms

Not enough minerals.

Claude Code reports why a turn failed. Rate limits, billing errors, and accounts on hold play the minerals line. Hitting the output token limit plays the vespene line. An optional status-line command shows how much of your tightest limit is left as minerals, and your context window as supply against the 200 cap. The advisor warns you once when the minerals run low, and once more when you are about to be supply blocked.

Codex pets

Coming soon.

The SCV and the Probe have reserved slots as native Codex pets. The manifests, installer, validation, and release packaging are ready; the artwork is not bundled yet. Until it ships, agent-starcraft pet install says so and changes nothing. Codex's own pet feature can make you one in the meantime.

Pets and sounds are independent. When the art lands, install either pet, both, or neither, with either faction's voice.

Install

Two commands. Good to go.It shall be done.

Run these in your terminal. Sounds need Node.js 22+ and a local audio player; restart your agent after installation.

Claude Code

claude plugin marketplace add mitchtech/agent-starcraft
claude plugin install starcraft@agent-starcraft

Codex

codex plugin marketplace add mitchtech/agent-starcraft
codex plugin add starcraft@agent-starcraft

Gemini CLI

gemini extensions install https://github.com/mitchtech/agent-starcraft

Review and trust the sound hooks in Codex's hook settings. Running a sibling plugin too (Navi, Johnny 5, Warcraft, Rocky, or Star Wars)? Enable one per host so they do not talk over each other. Other agents use the standalone event interface.

Sound controls
agent-starcraft status
agent-starcraft faction protoss
agent-starcraft faction random
agent-starcraft mute prompt_submitted
agent-starcraft unmute subagent_started
agent-starcraft preset attention
agent-starcraft unmute all

Or ask your agent to "switch to Protoss" or "mute the SCV" through the bundled control skill. Global mute preserves your event preferences.

Status-line meters
{
  "statusLine": {
    "type": "command",
    "command": "agent-starcraft statusline"
  }
}

Add this to your Claude Code settings.json after npm install -g github:mitchtech/agent-starcraft. The meters read the session JSON Claude Code already sends; nothing leaves your machine.
