# Preview images

The waveform GIFs, social card, README banners, and touch icon are generated by
[`scripts/build-assets.py`](../../scripts/build-assets.py) from the committed
clips in [`audio/`](../../audio). Pet preview GIFs join them automatically once
SCV or Probe pet art is bundled. The waveforms depict *StarCraft* audio, whose
rights remain with Blizzard Entertainment; see the
[audio rights notice](../../audio/NOTICE.md). The mineral crystal and faction
emblems are original drawings, not Blizzard artwork.

The generation code is MIT licensed. Card lettering uses the OFL-licensed fonts
listed in [site fonts](../../site/fonts/OFL.md). No affiliation with Blizzard
Entertainment is implied.
