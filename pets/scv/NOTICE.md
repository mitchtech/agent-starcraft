# SCV pet artwork

The SCV Codex pet is not bundled yet. This directory holds the manifest only,
so the installer, validation, and release packaging are ready for it. The site
and `doctor --pet` follow the Terran faction to this pet.

Until the art ships, `agent-starcraft pet install` reports that the pet is not bundled and
changes nothing. Codex's native pet feature can create a pet in the meantime.

When the art lands, add `spritesheet.webp` (8 x 11 atlas of 192 x 208 cells,
Codex sprite version 2), `LICENSE.txt` for the artwork, and its provenance here.
Validation, previews, and packaging enable themselves once the sprite sheet
exists; no code changes are needed. The art must be original: no sprites,
portraits, or models extracted from Blizzard games.
